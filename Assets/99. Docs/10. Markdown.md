## 마크다운 언어란?
마크업(Mark-Up) 언어의 경량화된 버전으로 현대 문서 편집기에 일관적으로 사용되는 언어이다.
마크다운 언어로 텍스트를 작성하면 해당 소스를 프로그램에서 읽어서 변환 후 사용자에 따라 맞춤형 출력이 가능하다.
보통 개발자들이 주로 사용하며, 게임회사의 경우 프로젝트의 위키를 제작하는데 사용된다.
프로그래머, 기획자, 디자이너들이 주로 사용한다.

## 문법
### 1. 제목 (Heading)
- `#`의 개수로 수준(Heading Level)을 구분한다.
```
# 제목 1
## 제목 2
### 제목 3
#### 제목 4
##### 제목 5
###### 제목 6
```
- 일반적으로는 2~3단계 정도 사용

### 2. 문단과 줄 바꿈
- 보통 한 줄을 띄우면 새로운 문단이 된다.
- 강제 줄바꿈은 문장 끝에 `두 개의 공백 + Enter`를 입력한다.
```
문단 1  << 스페이스 두번
문단 2
```
문단 1  
문단 2
### 3. 강조
```
*기울임* 또는 _기울임_
**굵게** 또는 __굵게__
***기울임과 굵게*** 또는 ___기울임과 굵게___
~~~취소선~~~
```
*기울임* 또는 _기울임_  
**굵게** 또는 __굵게__  
***기울임과 굵게*** 또는 ___기울임과 굵게___  
~~취소선~~

### 4. 목록(List)
#### 4.1. 순서없는 목록
```
- 항목 1
	- 하위 항목 1 (탭, 쉬프트 탭)
	- 하위 항목 2
* 항목 2
	* 하위 항목 2
+ 항목 3
	+ 하위 항목 3
```
- 항목 1
	- 하위 항목 1 (탭, 쉬프트 탭)
	- 하위 항목 2
* 항목 2
	* 하위 항목 2
+ 항목 3
	+ 하위 항목 3
#### 4.2. 순서 있는 목록
```
1. 첫번째
2. 두번째
	1. 하위 첫번째
	2. 하위 두번째
	3. 하위 세번째 ...
```
1. 첫번째
2. 두번째
	1. 하위 첫번째
	2. 하위 두번째
	3. 하위 세번째 ...
### 5. 코드 (Code)
**코드 블록**
```csharp
public static void Main()
{
	Console.WriteLine("Hello");
}
// 플러그인이 있으면 C# 코드 색으로 나옴
```
**인용**
```
> 인용문은 꺽쇠로 작성 가능
>> 두 번도 가능함
```
> 인용문은 꺽쇠로 작성 가능
>> 두 번도 가능함
>>> 세 번도 가능함


### 7. 테이블
```
|항목|설명|예시|
|---|---|---|
|정렬|:--|왼쪽 정렬|
|정렬|--:|오른쪽 정렬|
|정렬|:--|왼쪽 정렬|
```
|항목|설명|예시|
|:--|:-:|--:|
|정렬|:--|왼쪽 정렬|
|정렬예시|--:|오른쪽 정렬|
|정렬|:-:|가운데 정렬|
### 8. 체크리스트

- [ ] 미완료된 항목
