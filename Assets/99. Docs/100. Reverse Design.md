## 1. 문서 개요

본 문서는 포켓몬스터 하트골드를 대상으로 한 역기획서입니다.

분석의 중심 주제는 포켓몬스터 시리즈의 핵심 요소 중 하나인 **상성 시스템**입니다.

본 문서에서는 상성 시스템을 단순한 타입별 유불리 규칙으로 보지 않고, 다음 흐름 속에서 분석합니다.

```text
컨셉 기획 : 의도
시스템 기획 : 설계
데이터 기획 : 구현
```

즉, 이 문서는 다음 질문에 답하는 것을 목표로 합니다.

```text
왜 포켓몬마다 다른 역할이 필요합니까?
→ 상성 시스템은 그 의도를 어떤 플레이 구조로 만듭니까?
→ 그 시스템은 어떤 데이터로 구현됩니까?
```

본 문서는 하트골드의 모든 콘텐츠를 총망라하는 문서가 아니라, **상성 시스템과 연결되는 컨셉·시스템·데이터 요소를 중심으로 재구성한 역기획서**입니다.

본 문서는 실제 개발 문서를 기준으로 한 것이 아니라, 완성된 게임에서 관찰 가능한 구조를 바탕으로 작성한 역기획 분석입니다.
따라서 “개발자가 의도했다”고 단정하지 않고, “구조상 이렇게 기능한다”, “결과적으로 이런 역할을 한다”는 방식으로 서술합니다.

## 3. 컨셉 기획 분석

### 3-1. 한 줄 컨셉

> **포켓몬을 발견하고, 포획하고, 육성하여 상황에 맞게 운용하는 수집형 턴제 RPG**

포켓몬스터 하트골드는 단순히 포켓몬을 많이 모으는 게임에 그치지 않습니다.
플레이어는 다양한 포켓몬을 수집한 뒤, 각 포켓몬의 타입, 기술, 능력치, 역할을 고려하여 전투와 탐험에 활용합니다.

이때 상성 시스템은 “어떤 포켓몬을 포획하고 육성하고 사용할 것인가”를 판단하게 만드는 핵심 기준으로 작동합니다.

---

### 3-2. 핵심 경험

| 핵심 경험 | 내용                                    | 상성 시스템과의 관계                   |
| ----- | ------------------------------------- | ----------------------------- |
| 수집    | 지역, 시간, 조건에 따라 다양한 포켓몬을 발견하고 포획합니다.   | 새로운 타입과 역할을 확보하게 만듭니다.        |
| 육성    | 레벨업, 진화, 기술 습득을 통해 포켓몬을 성장시킵니다.       | 어떤 포켓몬과 기술을 키울지 판단하게 만듭니다.    |
| 전투    | 턴제 전투 안에서 기술 사용, 교체, 아이템 사용을 선택합니다.   | 매 턴 기술 선택과 교체 판단의 기준이 됩니다.    |
| 탐험    | 성도와 관동을 이동하며 새로운 지역, 포켓몬, 아이템을 발견합니다. | 새로운 상성 대응 수단을 찾는 동기가 됩니다.     |
| 동행    | 첫 번째 포켓몬이 플레이어를 따라다니며 동료감을 강화합니다.     | 전략적으로 선택한 포켓몬에 정서적 의미를 부여합니다. |

이 중 상성 시스템과 가장 직접적으로 연결되는 요소는 수집, 육성, 전투, 탐험입니다.
동행 경험은 상성 시스템과 같은 층위의 전투 규칙은 아니지만, 플레이어가 선택하고 키운 포켓몬에 애착을 갖게 만들어 수집과 육성의 의미를 강화합니다.

---

### 3-3. 하트골드의 차별적 경험 요소

하트골드는 원작 금·은의 구조를 기반으로 하면서, 닌텐도 DS 환경에 맞춘 신규 요소를 더한 리메이크입니다.

| 요소              | 역할                                      |
| --------------- | --------------------------------------- |
| 성도 + 관동 2개 지방   | 1차 엔딩 이후 세계가 확장되는 장기 진행 구조를 제공합니다.      |
| 체육관 16개         | 성도 8개, 관동 8개 체육관을 통해 장기적인 공략 목표를 제공합니다. |
| 동반 보행 시스템       | 파티 첫 번째 포켓몬이 플레이어를 따라다니며 동료감을 강화합니다.    |
| 포켓워커            | 현실의 걸음 수를 포켓몬 성장과 보상으로 연결합니다.           |
| 터치 UI / 포켓슬론    | 닌텐도 DS 환경에 맞춘 조작과 미니게임 경험을 제공합니다.       |
| 배틀프론티어 / 재도전 요소 | 메인 클리어 이후 고난도 전투와 반복 플레이 목표를 제공합니다.     |

이 요소들은 하트골드의 차별적 경험을 구성합니다.
다만 본 역기획서의 중심축에서 보면, 이 요소들은 상성 시스템 자체라기보다 **수집, 육성, 탐험, 전투를 더 오래 지속하게 만드는 확장 요소**입니다.

---

### 3-4. 컨셉에서 상성 시스템으로 이어지는 구조

하트골드의 핵심 컨셉은 다음 흐름으로 시스템화됩니다.

```text
다양한 포켓몬을 발견합니다.
→ 포켓몬을 포획합니다.
→ 포켓몬을 육성합니다.
→ 타입과 기술을 고려해 파티를 구성합니다.
→ 전투에서 상성을 판단합니다.
→ 체육관과 주요 전투를 공략합니다.
→ 새로운 지역으로 이동해 다시 탐험합니다.
```

이 구조가 성립하려면 포켓몬마다 단순한 능력치 이상의 차이가 필요합니다.
상성 시스템은 이 차이를 전투 규칙으로 구현합니다.

| 컨셉 요구                            | 시스템 방향                             |
| -------------------------------- | ---------------------------------- |
| 다양한 포켓몬을 수집하게 해야 합니다.            | 포켓몬마다 타입과 역할을 다르게 부여합니다.           |
| 한 포켓몬만으로 모든 상황을 해결하기 어렵게 해야 합니다. | 상성에 따른 유불리를 만듭니다.                  |
| 수집이 전투 선택지 확장으로 이어져야 합니다.        | 다양한 타입의 포켓몬을 파티에 넣게 만듭니다.          |
| 전투가 단순 레벨 싸움이 아니어야 합니다.          | 기술 타입과 방어 타입의 관계로 피해 효율을 다르게 만듭니다. |
| 플레이어가 게임 안에서 규칙을 배워야 합니다.        | 전투 피드백과 체육관 구조를 통해 상성을 학습하게 만듭니다.  |

따라서 상성은 “물은 불에 강하다” 수준의 단순 규칙이 아니라,
수집한 포켓몬을 실제 전투에서 상황에 맞게 운용하게 만드는 컨셉의 핵심 연결 장치입니다.

## 4. 시스템 기획 분석

### 4-1. 전체 플레이 루프

하트골드의 기본 플레이 루프는 다음과 같습니다.

```text
탐험
→ 조우
→ 전투 / 포획
→ 육성
→ 파티 구성
→ 상성 판단
→ 체육관 및 주요 전투 공략
→ 다음 지역 탐험
```

이 루프에서 상성 시스템은 전투 안에서만 작동하지 않습니다.
플레이어가 어떤 포켓몬을 포획하고, 어떤 기술을 남기고, 어떤 파티를 구성할지 판단하게 만드는 기준으로 작동합니다.

| 단계 | 내용                          | 상성과의 관계                   |
| -- | --------------------------- | ------------------------- |
| 탐험 | 마을, 도로, 동굴, 바다, 체육관을 이동합니다. | 새로운 타입과 대응 수단을 발견합니다.     |
| 조우 | 야생 포켓몬 또는 트레이너와 만납니다.       | 상대 타입과 보유 포켓몬을 확인합니다.     |
| 전투 | 기술 사용, 교체, 아이템 사용을 선택합니다.   | 기술 타입과 방어 타입의 유불리를 판단합니다. |
| 포획 | 야생 포켓몬을 파티 후보로 확보합니다.       | 파티의 타입 범위와 대응력을 확장합니다.    |
| 육성 | 레벨업, 진화, 기술 습득을 진행합니다.      | 특정 타입 대응을 강화합니다.          |
| 공략 | 체육관, 라이벌, 로켓단, 리그에 도전합니다.   | 상성 이해도와 파티 구성을 검증합니다.     |

---

### 4-2. 주요 하위 시스템

하트골드는 여러 하위 시스템이 서로 연결된 구조를 가집니다.

| 하위 시스템       | 역할                       | 상성과의 관계                       |
| ------------ | ------------------------ | ----------------------------- |
| 포획 및 육성 시스템  | 포켓몬을 확보하고 성장시킵니다.        | 상성 대응 가능한 파티 후보를 늘립니다.        |
| 전투 시스템       | 턴 단위 선택과 결과 판정을 처리합니다.   | 기술 선택과 교체 판단의 중심 기준이 됩니다.     |
| 체육관 및 리그 시스템 | 진행 목표와 난이도 검증을 제공합니다.    | 특정 타입 중심 전투로 상성 이해를 시험합니다.    |
| 탐험 시스템       | 새로운 지역, 포켓몬, 아이템을 제공합니다. | 새로운 대응 수단을 찾게 만듭니다.           |
| 도감 / 포켓기어    | 수집과 탐험을 보조합니다.           | 필요한 포켓몬과 반복 전투를 찾는 데 도움을 줍니다. |
| 동반 보행 / 포켓워커 | 동행감과 현실 연동 경험을 제공합니다.    | 선택한 포켓몬에 대한 애착과 장기 육성을 강화합니다. |

이 중 상성 시스템과 가장 직접적으로 맞물리는 것은 전투, 포획, 육성, 체육관, 탐험입니다.
동반 보행과 포켓워커는 상성 판정에 직접 개입하지 않지만, 플레이어가 포켓몬을 “교체 가능한 유닛”이 아니라 “함께 키운 파트너”로 느끼게 만드는 보조 축입니다.

### 4-3. 전투 시스템

하트골드의 전투는 기본적으로 1:1 싱글 턴제 전투를 중심으로 하며, 일부 상황에서는 더블 배틀 및 멀티 배틀 구조도 사용됩니다.

플레이어는 매 턴 다음 행동 중 하나를 선택합니다.

| 행동     | 설명                             |
| ------ | ------------------------------ |
| 기술 사용  | 포켓몬이 가진 최대 4개의 기술 중 하나를 선택합니다. |
| 아이템 사용 | 회복, 상태이상 치료, 포획 등을 시도합니다.      |
| 포켓몬 교체 | 파티의 다른 포켓몬으로 교체합니다.            |
| 도망     | 야생 전투에서 전투를 중단합니다.             |

전투를 구성하는 주요 요소는 다음과 같습니다.

| 요소          | 역할                       |
| ----------- | ------------------------ |
| HP          | 포켓몬의 생존 여부를 결정합니다.       |
| 공격 / 방어     | 물리 기술의 피해량에 영향을 줍니다.     |
| 특수공격 / 특수방어 | 특수 기술의 피해량에 영향을 줍니다.     |
| 스피드         | 행동 순서를 결정합니다.            |
| 타입          | 상성 판정의 기준이 됩니다.          |
| 기술          | 공격, 보조, 상태이상 등 행동 수단입니다. |
| 상태이상        | 전투 흐름과 행동 가능성을 변화시킵니다.   |
| 교체          | 불리한 상황을 바꾸는 전략적 선택입니다.   |

전투는 단순한 레벨 싸움이 아닙니다.
플레이어는 상대 포켓몬의 타입, 보유 기술, 남은 HP, 교체 가능성 등을 고려해야 합니다.

상성 시스템은 이 판단의 중심에 있습니다.

```text
현재 포켓몬이 상대의 공격을 버틸 수 있습니까?
현재 기술이 상대에게 효과적입니까?
교체를 통해 더 유리한 상성을 만들 수 있습니까?
```

---

### 4-4. 포획 및 육성 시스템

포획 시스템은 야생 포켓몬을 단순히 쓰러뜨리는 것이 아니라, 파티 후보로 전환하는 시스템입니다.

포획은 다음 요소의 영향을 받습니다.

| 요소          | 역할                                     |
| ----------- | -------------------------------------- |
| 포켓몬의 기본 포획률 | 포켓몬마다 포획 난이도를 다르게 만듭니다.                |
| 현재 HP       | HP가 낮을수록 포획 성공 가능성이 높아집니다.             |
| 상태이상        | 잠듦 / 얼음 / 마비 / 독 / 화상 등이 포획에 영향을 줍니다.  |
| 볼 종류        | 몬스터볼, 슈퍼볼, 하이퍼볼, 특수 볼 등에 따라 보정이 달라집니다. |

포획 전략은 크게 세 가지로 정리할 수 있습니다.

```text
HP를 낮춥니다.
→ 상태이상을 부여합니다.
→ 상황에 맞는 볼을 선택합니다.
```

포획은 상성 시스템과 직접 계산식으로 연결되지는 않지만, 상성 대응 능력을 확장하는 중요한 수단입니다.
새로운 포켓몬을 잡는 것은 새로운 타입, 기술, 방어 상성, 파티 역할을 확보하는 행위입니다.

육성 시스템은 포켓몬의 전투 성능을 장기적으로 변화시킵니다.

| 육성 요소 | 역할                                     |
| ----- | -------------------------------------- |
| 레벨업   | 능력치 상승과 기술 습득을 제공합니다.                  |
| 진화    | 외형, 능력치, 역할 변화를 제공합니다.                 |
| 기술 습득 | 전투 중 선택 가능한 행동을 확장합니다.                 |
| 친밀도   | 일부 포켓몬의 진화 조건, 은혜갚기/화풀이 위력 등에 영향을 줍니다. |
| 학습장치  | 지닌 포켓몬이 직접 전투하지 않아도 경험치를 받을 수 있게 합니다.  |

하트골드 기준으로 야생 포켓몬을 포획하는 것 자체는 경험치 획득으로 이어지지 않습니다.
경험치는 기본적으로 상대 포켓몬을 쓰러뜨렸을 때 획득합니다.

---

### 4-5. 체육관 및 리그 도전 시스템

체육관은 진행 목표이자, 상성 이해도를 검증하는 대표적인 구조입니다.

하트골드의 성도 체육관은 대체로 특정 타입을 중심으로 구성됩니다.

| 순서 | 지역    | 관장 | 중심 타입 |
| -- | ----- | -- | ----- |
| 1  | 도라지시티 | 비상 | 비행    |
| 2  | 고동마을  | 호일 | 벌레    |
| 3  | 금빛시티  | 꼭두 | 노말    |
| 4  | 인주시티  | 유빈 | 고스트   |
| 5  | 진청시티  | 사도 | 격투    |
| 6  | 담청시티  | 규리 | 강철    |
| 7  | 황토마을  | 류옹 | 얼음    |
| 8  | 검은먹시티 | 이향 | 드래곤   |

체육관은 다음 역할을 합니다.

| 요소       | 역할                                         |
| -------- | ------------------------------------------ |
| 타입 테마    | 특정 타입에 대한 대응을 요구합니다.                       |
| 체육관 트레이너 | 관장 전투 전 전투 경험과 힌트를 제공합니다.                  |
| 퍼즐 / 동선  | 전투 외 진행감을 만듭니다.                            |
| 관장 전투    | 파티 구성과 상성 이해도를 검증합니다.                      |
| 배지 보상    | 진행 권한, 일부 HM 필드 사용, 교환 포켓몬 복종 레벨 등과 연결됩니다. |

체육관 전투는 별도의 날씨나 필드 효과가 자동 적용되는 전투가 아니라, 기본 턴제 전투 규칙 안에서 타입 테마와 포켓몬 구성을 통해 난이도를 만듭니다.

성도 리그는 사천왕과 챔피언으로 구성됩니다.

| 순서  | 인물 | 중심 타입 / 성향 |
| --- | -- | ---------- |
| 1   | 일목 | 에스퍼        |
| 2   | 독수 | 독          |
| 3   | 시바 | 격투         |
| 4   | 카렌 | 악          |
| 챔피언 | 목호 | 드래곤 중심     |

리그는 연속 전투 구조를 통해 파티 전체의 안정성과 대응 범위를 검증합니다.
한두 타입만 강하게 키운 파티보다, 다양한 타입과 기술을 가진 파티가 장기전에 대응하기 쉽습니다.

### 4-6. 상성 시스템

상성 시스템은 **기술 타입**과 **방어 포켓몬의 타입**을 비교해 공격 효과를 결정하는 규칙입니다.

4세대 하트골드/소울실버 기준 타입은 총 17개입니다.
페어리 타입은 존재하지 않습니다.

상성 판정의 기본 구조는 다음과 같습니다.

```text
공격 기술 타입 × 방어 포켓몬 타입 = 대미지 배율
```

| 배율    | 의미               | 전투 피드백 예시   |
| ----- | ---------------- | ----------- |
| 0배    | 공격이 통하지 않습니다.    | 효과가 없다는 피드백 |
| 0.25배 | 복합 타입의 이중 반감입니다. | 효과가 낮다는 피드백 |
| 0.5배  | 공격 효율이 낮습니다.     | 효과가 낮다는 피드백 |
| 1배    | 일반 대미지입니다.       | 별도 강조 없음    |
| 2배    | 공격 효율이 높습니다.     | 효과가 크다는 피드백 |
| 4배    | 복합 타입의 이중 약점입니다. | 효과가 크다는 피드백 |

방어 포켓몬이 두 개의 타입을 가진 경우, 두 타입의 상성 배율이 곱해집니다.

예를 들어 물/비행 타입 포켓몬이 전기 타입 기술을 받을 경우 다음처럼 계산됩니다.

```text
전기 기술 → 물 타입: 2배
전기 기술 → 비행 타입: 2배

최종 배율: 2 × 2 = 4배
```

상성 시스템은 다음 판단을 만듭니다.

```text
어떤 기술을 사용할 것인가?
현재 포켓몬으로 계속 싸울 것인가?
다른 포켓몬으로 교체할 것인가?
파티가 특정 타입에 지나치게 취약하지 않은가?
체육관 공략 전 어떤 포켓몬을 준비해야 하는가?
```

따라서 상성 시스템은 전투 피해량을 조절하는 규칙을 넘어, 포획, 육성, 파티 구성, 체육관 공략을 연결하는 중심 시스템입니다.

## 5. 데이터 기획 분석

### 5-1. 시스템 요구에서 데이터 구조로

상성 시스템이 실제 게임 안에서 작동하려면, 시스템 요구가 데이터 구조로 전환되어야 합니다.

| 시스템 요구                      | 필요한 데이터                          |
| --------------------------- | -------------------------------- |
| 포켓몬마다 상성상 강점과 약점이 있어야 합니다.  | 포켓몬 타입 데이터                       |
| 기술마다 공격 상성 판정이 가능해야 합니다.    | 기술 타입 데이터                        |
| 타입 간 유불리를 계산해야 합니다.         | 상성 매트릭스 데이터                      |
| 상성 결과가 실제 피해량에 반영되어야 합니다.   | 능력치, 기술 위력, 대미지 계산 데이터           |
| 플레이어가 상성 대응을 준비할 수 있어야 합니다. | 야생 포켓몬 출현, 기술 습득, TM/HM, 아이템 데이터 |
| 게임 진행 중 상성을 학습할 수 있어야 합니다.  | 체육관 타입 구성, 전투 피드백, 반복 전투 구조      |
| 수집과 전투가 연결되어야 합니다.          | 도감, 출현 위치, 포획, 진화, 파티 데이터        |

하트골드의 데이터는 단순히 포켓몬과 아이템의 목록이 아닙니다.
각 데이터는 플레이어가 상성을 이해하고, 준비하고, 활용하게 만드는 구조의 일부로 기능합니다.

### 5-2. 타입 및 상성 데이터

타입 데이터는 포켓몬과 기술 양쪽에 부여됩니다.

| 적용 대상  | 역할                          |
| ------ | --------------------------- |
| 포켓몬 타입 | 방어 상성, 자속 보정, 파티 역할을 결정합니다. |
| 기술 타입  | 공격 상성, 기술 선택, 견제 범위를 결정합니다. |

상성 데이터는 타입 간 관계를 저장하는 참조 테이블입니다.

```text
상성 매트릭스
= 공격 기술 타입과 방어 포켓몬 타입의 배율 관계
```

이 데이터는 전투 중 피해량을 바꾸는 동시에, 플레이어의 기술 선택과 교체 판단을 유도합니다.

---

### 5-3. 포켓몬 데이터

포켓몬 데이터는 전투, 수집, 육성 시스템의 중심 데이터입니다.

| 데이터 항목  | 역할                       |
| ------- | ------------------------ |
| 도감 번호   | 수집 및 식별 기준입니다.           |
| 이름 / 분류 | 포켓몬의 개별 정체성을 나타냅니다.      |
| 타입      | 방어 상성, 자속, 파티 역할을 결정합니다. |
| 능력치     | 전투 성능의 기본값입니다.           |
| 특성      | 전투 중 자동 발동하는 패시브 효과입니다.  |
| 진화 정보   | 장기 육성 목표를 제공합니다.         |
| 획득 정보   | 탐험과 수집 동선을 만듭니다.         |
| 습득 기술   | 전투 선택지를 결정합니다.           |

포켓몬은 단순한 캐릭터 데이터가 아니라, 타입, 능력치, 특성, 기술, 진화, 획득 위치가 결합된 복합 데이터입니다.

스타팅 포켓몬 3종은 초반부터 타입, 상성, 능력치 방향성, 육성 차이를 비교하게 만드는 대표 데이터입니다.

| 포켓몬  | 타입 | 특성 | 기획적 역할                                                    |
| ---- | -- | -- | --------------------------------------------------------- |
| 치코리타 | 풀  | 심록 | 방어적 능력치 성향을 가지지만, 풀 타입의 약점 때문에 파티 보완 필요성을 초반부터 체감하게 만듭니다. |
| 브케인  | 불꽃 | 맹화 | 빠른 스피드와 특수공격 중심으로 공격적인 진행감을 제공합니다.                        |
| 리아코  | 물  | 급류 | 물 타입의 안정적인 상성과 물리 공격 성향을 통해 균형 잡힌 진행을 제공합니다.              |

### 5-4. 기술 데이터

기술 데이터는 포켓몬이 전투 중 선택할 수 있는 행동입니다.

| 항목    | 역할                            |
| ----- | ----------------------------- |
| 타입    | 상성 판정의 기준이 됩니다.               |
| 분류    | 물리 / 특수 / 변화로 나뉩니다.           |
| 위력    | 대미지 계산의 기본값이 됩니다.             |
| 명중률   | 기술 성공 여부에 영향을 줍니다.            |
| PP    | 기술 사용 가능 횟수를 제한합니다.           |
| 부가 효과 | 상태이상, 능력치 변화, 특수 조건 등을 부여합니다. |

4세대부터는 기술의 물리/특수 여부가 타입이 아니라 기술 개별 데이터로 분리됩니다.

| 기술 분류 | 참조 데이터       | 역할                          |
| ----- | ------------ | --------------------------- |
| 물리    | 공격 vs 방어     | 물리 피해를 계산합니다.               |
| 특수    | 특수공격 vs 특수방어 | 특수 피해를 계산합니다.               |
| 변화    | 별도 효과        | 상태이상, 능력치 변화, 보조 효과를 적용합니다. |

이 구조 덕분에 플레이어는 단순히 기술 위력만 보는 것이 아니라, 포켓몬의 능력치 성향과 기술 타입을 함께 고려하게 됩니다.

### 5-5. 능력치 / 특성 / 성장 데이터

능력치 데이터는 포켓몬의 기본 전투 성능을 구성합니다.

| 능력치  | 역할                   |
| ---- | -------------------- |
| HP   | 포켓몬의 전투 지속력을 결정합니다.  |
| 공격   | 물리 기술의 피해량에 영향을 줍니다. |
| 방어   | 물리 기술로 받는 피해를 줄입니다.  |
| 특수공격 | 특수 기술의 피해량에 영향을 줍니다. |
| 특수방어 | 특수 기술로 받는 피해를 줄입니다.  |
| 스피드  | 행동 순서를 결정합니다.        |

성장 관련 데이터는 장기 육성 방향을 만듭니다.

| 데이터   | 역할                                 |
| ----- | ---------------------------------- |
| 레벨    | 경험치 축적에 따른 성장 단계입니다.               |
| 진화 조건 | 레벨, 아이템, 친밀도, 교환 등으로 장기 목표를 제공합니다. |
| 개체값   | 포켓몬마다 다른 선천적 능력 차이를 만듭니다.          |
| 노력치   | 전투 경험에 따른 후천적 능력 성장을 만듭니다.         |
| 성격    | 일부 능력치에 보정치를 부여해 개체별 차이를 만듭니다.     |
| 특성    | 전투 중 특정 조건에서 자동 발동하는 패시브 효과입니다.    |

이 데이터들은 상성 시스템과 직접 같은 표에 들어가지는 않지만, 포켓몬의 역할과 운용 방향을 결정합니다.
상성이 유리해도 능력치가 부족하면 결정력이 낮을 수 있고, 능력치가 높아도 불리한 상성에서는 위험해질 수 있습니다.

### 5-6. 아이템 및 TM/HM 데이터

아이템 데이터는 포획, 회복, 육성, 전투, 탐험을 보조합니다.

| 분류    | 역할                         | 예시                    |
| ----- | -------------------------- | --------------------- |
| 포획    | 야생 포켓몬을 잡습니다.              | 몬스터볼, 슈퍼볼, 하이퍼볼, 특수 볼 |
| 회복    | HP, PP, 상태이상을 회복합니다.       | 상처약, 풀회복약             |
| 진화    | 특정 포켓몬의 진화를 유도합니다.         | 번개의 돌, 태양의돌           |
| 육성    | 레벨 또는 능력 성장에 영향을 줍니다.      | 이상한사탕, 타우린            |
| 전투 보조 | 전투 중 능력치나 기술 효율에 영향을 줍니다.  | 플러스파워, 자뭉열매           |
| 기술 습득 | 포켓몬에게 기술을 가르칩니다.           | TM, HM                |
| 필드 진행 | 이동, 장애물 해제, 스토리 진행에 사용됩니다. | 자전거, 중요한 물건           |

TM과 HM은 아이템 데이터와 기술 데이터를 연결하는 매개 데이터입니다.

```text
TM/HM 획득
→ 특정 기술 습득
→ 포켓몬별 습득 가능 여부 판정
→ 전투 선택지 확장
→ HM의 경우 필드 진행 기능까지 연결
```

| 구분 | 특징                       | 기획적 역할                       |
| -- | ------------------------ | ---------------------------- |
| TM | 4세대 기준 일회용 기술 습득 아이템입니다. | 제한된 자원을 누구에게 사용할지 고민하게 만듭니다. |
| HM | 반복 사용 가능한 기술 습득 아이템입니다.  | 전투 기술과 필드 이동 기능을 동시에 가집니다.   |

TM/HM은 상성 대응 능력을 확장합니다.
플레이어는 기존 파티에 부족한 공격 타입이나 필드 진행 기능을 기술 습득을 통해 보완할 수 있습니다.

### 5-7. 수집 및 탐험 보조 데이터

도감과 포켓기어는 직접 전투 계산에 개입하지 않지만, 수집과 탐험의 장기 동기를 제공합니다.

| 데이터        | 역할                            |
| ---------- | ----------------------------- |
| 성도 도감      | 성도 지방에서 만나는 포켓몬 수집 목표를 제공합니다. |
| 전국 도감      | 엔딩 이후 더 넓은 수집 목표를 제공합니다.      |
| 포켓기어 - 시계  | 시간대와 요일 이벤트를 확인합니다.           |
| 포켓기어 - 전화  | 트레이너 재배틀, 이벤트 알림 등을 제공합니다.    |
| 포켓기어 - 지도  | 지역 이동과 위치 파악을 보조합니다.          |
| 포켓기어 - 라디오 | 특정 이벤트와 포켓몬 조우에 연결됩니다.        |

이 데이터들은 상성 계산을 직접 수행하지는 않습니다.
하지만 플레이어가 필요한 포켓몬, 아이템, 재배틀 기회를 찾는 과정을 보조하여 상성 대응 수단을 확보하게 만듭니다.

## 6. 컨셉 / 시스템 / 데이터 연결 정리

하트골드의 상성 중심 구조는 다음과 같이 정리할 수 있습니다.

| 단계  | 핵심 내용                                    | 상성 시스템의 위치                                   |
| --- | ---------------------------------------- | -------------------------------------------- |
| 컨셉  | 다양한 포켓몬을 수집하고 상황에 맞게 운용합니다.              | 포켓몬마다 다른 역할과 강점, 약점이 필요합니다.                  |
| 시스템 | 전투, 교체, 포획, 육성, 체육관 구조가 플레이 판단을 만듭니다.    | 기술 선택, 교체, 파티 구성, 체육관 공략의 기준이 됩니다.           |
| 데이터 | 타입, 기술, 능력치, 특성, 아이템, 출현 위치가 구현 기반이 됩니다. | 포켓몬 타입, 기술 타입, 상성 매트릭스로 실제 배율과 판단 구조를 구현합니다. |

이를 더 구체적으로 풀면 다음과 같습니다.

```text
컨셉:
포켓몬을 많이 모으는 것만으로는 부족합니다.
각 포켓몬을 상황에 맞게 운용해야 합니다.

시스템:
전투에서는 기술 선택, 교체, 포획, 육성, 체육관 공략이 반복됩니다.
상성은 이 선택들을 연결하는 판단 기준입니다.

데이터:
포켓몬 타입, 기술 타입, 상성 매트릭스, 능력치, 특성, 기술, 아이템, 출현 위치가
상성 중심 플레이를 실제로 작동하게 만듭니다.
```

상성 시스템은 전투 안에서만 존재하는 규칙이 아닙니다.
상성은 포켓몬을 잡는 이유, 키우는 방향, 기술을 고르는 기준, 파티를 구성하는 논리, 체육관을 공략하는 방법을 연결합니다.

## 7. 최종 요약

포켓몬스터 하트골드는 **다양한 포켓몬을 수집하고, 육성하고, 상황에 맞게 운용하는 수집형 턴제 RPG**입니다.

이 컨셉이 성립하려면 포켓몬마다 서로 다른 역할과 강점, 약점이 필요합니다.
상성 시스템은 그 차이를 전투 규칙으로 구현하여, 플레이어가 포켓몬을 단순히 많이 모으는 것이 아니라 상황에 맞게 선택하고 활용하도록 만듭니다.

시스템 측면에서 상성은 기술 선택, 교체, 파티 구성, 체육관 공략, 난이도 조절을 연결합니다.
플레이어는 레벨이 높은 포켓몬 하나에만 의존하기보다, 다양한 타입과 기술을 가진 포켓몬을 조합하고 상황에 맞게 운용하게 됩니다.

데이터 측면에서 상성은 포켓몬 타입, 기술 타입, 상성 매트릭스, 능력치, 기술 분류, 특성, 아이템, 출현 위치와 연결됩니다.
이 데이터들이 결합되어 상성 시스템은 실제 플레이 가능한 규칙으로 작동합니다.

하트골드의 차별적 경험을 구성하는 요소인 성도+관동의 이중 구조, 동반 보행 시스템, 포켓워커, 포켓슬론, 배틀프론티어 등은 이 플레이 경험을 확장합니다.
이 요소들은 상성 시스템 자체는 아니지만, 수집, 육성, 탐험, 전투의 반복을 더 오래 지속하게 만드는 요소입니다.

결과적으로 하트골드의 기획 구조는 다음과 같이 정리할 수 있습니다.

```text
다양한 포켓몬을 수집하고 상황에 맞게 운용한다는 컨셉
→ 타입 상성, 턴제 전투, 교체, 포획, 육성, 체육관 구조라는 시스템
→ 포켓몬 타입, 기술 타입, 상성 매트릭스, 능력치, 기술, 특성, 아이템, 출현 위치라는 데이터
```

따라서 본 역기획서의 분석 관점에서, 포켓몬스터 하트골드의 상성 시스템은 개별 전투 규칙이 아니라
**컨셉을 시스템으로 전환하고, 시스템을 데이터로 구현하게 만드는 중심 기획 축**으로 볼 수 있습니다.
